# Ancient Ruins 9minecraft Mod - Loot Crumbling Towers and Forgotten Crypts

Ancient Ruins 9minecraft Mod populates your world with hundreds of hand-built abandoned structures. This mod replaces empty fields with broken towers, sunken crypts, and hidden underground rooms. You can search these forgotten builds for loot chests filled with useful items. Each structure fits into its home biome naturally and only shows up in newly generated areas. Features: Fills the Overworld with hundreds of hand-crafted ruins instead of plain terrain.

## What this build is

Built and maintained in-house by 9Minecraft Studios.

Loader: Fabric, Forge, NeoForge.
